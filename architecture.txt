مخطط عمل تطبيق P2P Chat:

1. الـ Protocol المستخدم: TCP (Transmission Control Protocol) لضمان موثوقية وصول الرسائل.
2. الـ Addressing: يعتمد التطبيق على الـ IPv4 للشبكة المحلية LAN.
3. الـ Logic: 
   - كل مستخدم يعمل كـ Peer (Node).
   - يتم فتح ServerSocket للاستماع المستمر (Listening).
   - عند الإرسال، يتم إنشاء Socket مؤقت ينتهي بانتهاء تسليم البيانات.
4. الـ Security (خطة مستقبلية): سيتم تشفير البيانات المرسلة قبل تمريرها عبر الـ Socket.
