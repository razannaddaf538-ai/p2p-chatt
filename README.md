# P2P Chat Project - University Lab
تطبيق دردشة (نقطة لنقطة) يعتمد على بروتوكول TCP/IP للاتصال المباشر بين الأجهزة دون الحاجة لسيرفر وسيط.

## المميزات الحالية (النسخة الجزئية):
- إمكانية فتح منفذ استقبال (Server Socket).
- إمكانية الاتصال بـ IP معين وإرسال بيانات نصية.
- العمل بالكامل على الشبكة المحلية LAN.

## الأدوات المستخدمة:
- لغة Dart.
- مكتبة Dart:io للتعامل مع الشبكات.
