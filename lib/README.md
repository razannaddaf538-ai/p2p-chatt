# وصف ملفات واجهة دردشة Flutter

يتضمن هذا المجلد ملفات واجهة المستخدم لتطبيق P2P Chat:

- `app_colors.dart` - ألوان التطبيق الثابتة.
- `app_them.dart` - إعدادات الـ Theme للتطبيق.
- `chat_bubble.dart` - مكوّن فقاعة الرسائل.
- `chatscreen.dart` - شاشة المحادثة التي تحتوي على خادم/عميل TCP بسيط.
- `login.dart` - شاشة تسجيل الدخول (تنتقل إلى MainScreen).
- `main.dart` - نقطة الدخول لتشغيل التطبيق.
- `mainscreen.dart` - الشاشة الرئيسية مع شريط تنقل سفلي.
- `peersScreen.dart` - قائمة الأقران (نماذج مع عناوين IP افتراضية).

ملاحظة سريعة:
- هذه الملفات تعمل كبداية لتطبيق P2P محلي عبر شبكات محلية (LAN). خادم TCP في `chatscreen.dart` يستخدم Port 4040 ويستمع لرسائل نصية مباشرة.
- قبل الاعتماد على هذا الأسلوب في بيئة إنتاجية، يجب معالجة الأمان، إدارة الجلسات، وإضافة التعامل مع الصلاحيات للشبكة.
